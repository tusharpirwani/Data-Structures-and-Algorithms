# Data Structures and Algorithms (COMP1002)

**Course:** Data Structures and Algorithms - Curtin University

**Overview**
This repository showcases foundational computer science concepts, algorithmic efficiency, and memory management implemented entirely from scratch in Python. It contains both weekly skill-building practicals and a comprehensive final capstone project.

**Repository Structure**

* **`COMP1002_Assignment_22464293/` (Final Capstone: Hospital Management System)**
  Integrates custom-built graphs, hash tables, heaps, and sorting algorithms to process and manage patient records from CSV datasets. It demonstrates the ability to combine individual data structures into a cohesive, modular application. *(See the `README.txt` and `Technical_report_DSA.pdf` inside this folder for specific technical details).*

* **`Prac_01` to `Prac_09` (Weekly Practicals)**
  Individual implementations of core structures used to build the final assignment:
  * Linear Data Structures: Custom Linked Lists, Stacks, and Queues
  * Non-Linear Data Structures: Binary Search Trees (BST) and Graphs
  * Algorithms: Recursive algorithms (Towers of Hanoi, Fibonacci) and advanced sorting methods
  * Analysis: Time complexity testing and Big O performance analysis

**Technical Skills Demonstrated**
* **Language:** Python 3
* **Concepts:** Advanced data modeling, algorithmic efficiency, file I/O operations, and modular software design.
